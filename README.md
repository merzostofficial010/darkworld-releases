# DarkWorld

Официальные релизы игры **DarkWorld** и манифест автообновления.

- Скачать последнюю версию: [Releases](https://github.com/merzostofficial010/darkworld-releases/releases/latest)
- Манифест обновлений: [`update.json`](update.json)
- Разработчик: **merzost**

Игра работает офлайн. Автообновление проверяет `update.json`, скачивает новый APK и запускает установщик.
